# 视觉数据集管理平台使用手册

本文档面向部门内部平台使用者，介绍网站当前已经提供的操作功能。

> 本手册描述当前版本。数据集合并、审核中删除单张图片等功能仍在设计中，不属于当前可用功能。

## 1. 平台用途

平台用于统一管理视觉数据集、Label Studio 审核任务、UnitTrain 训练任务和训练输出模型。

一条典型工作流如下：

```text
准备服务器数据
  -> 分析并登记数据集 v1
  -> 在 Label Studio 中审核标注
  -> 结束审核并生成 v2
  -> 选择固定版本提交训练
  -> 查看指标、日志和输出模型
```

平台中的已发布版本是不可修改的。需要调整 `v2` 时，应从 `v2` 创建新的审核任务，完成后生成 `v3`，而不是覆盖原版本。

## 2. 访问平台

平台面向可信的部门内部网络，不设置平台登录、用户管理或角色权限。直接在浏览器中打开部署服务器的地址（例如 `http://10.10.16.58:8080`），页面会自动进入“数据集”。所有使用者都可以使用数据集、审核、训练和系统管理功能。

平台与 Label Studio 是两个独立应用。平台的 API Token 只供后端调用 Label Studio API，不能代替 Label Studio 浏览器会话。

## 3. 页面导航

左侧导航栏包含：

- **数据集**：登记、搜索、查看和归档数据集。
- **审核任务**：查看所有 Label Studio 审核任务及其进度。
- **训练任务**：查看所有 UnitTrain 训练任务。
- **模型**：查看训练完成后生成的模型。
- **系统管理**：配置来源目录、查看外部服务连接和审计日志；内部使用者均可进入。

可以通过侧边栏底部按钮收起或展开导航栏。

## 5. 准备数据集

### 5.1 数据必须位于服务器目录

当前网站不是浏览器上传工具。数据集必须提前放到服务器中，并且位于管理员配置的“允许访问目录”下面。

用户在登记时只能浏览允许目录，不能输入任意服务器绝对路径。如果目标目录没有显示，请联系管理员添加或启用来源目录。

### 5.2 纯图片目录

纯图片数据集可以使用以下结构：

```text
dataset/
└── images/
    ├── 00001.jpg
    ├── 00002.jpg
    └── 00003.png
```

纯图片目录没有标注，登记时必须填写“初始类别”。多个类别使用英文逗号分隔，例如：

```text
person, car, bicycle
```

登记后数据集通常处于“待标注”状态，可以创建 Label Studio 审核任务进行标注。

### 5.3 COCO 数据集

推荐结构：

```text
dataset/
├── images/
│   ├── 00001.jpg
│   └── 00002.jpg
└── annotations.json
```

`annotations.json` 必须是完整 COCO 对象，并包含：

```json
{
  "images": [],
  "annotations": [],
  "categories": []
}
```

重要要求：

- `images[].file_name` 必须是相对于所选数据集目录的有效路径，例如 `images/00001.jpg`。
- COCO 检测框格式是 `[x, y, width, height]`，不是 `[x1, y1, x2, y2]`。
- 框和分割掩码不能超出真实图片尺寸。
- 同一目录只能存在一个可识别的 COCO 或 Label Studio 标注源。
- 当前不接受同时存在 `annotations/train.json` 和 `annotations/val.json` 的目录。
- 多份 COCO JSON 应先合并为一个文件，再进行登记。

如果需要保留已有切分，可以在 COCO `images[]` 中添加：

```json
{
  "id": 1,
  "file_name": "images/00001.jpg",
  "width": 1920,
  "height": 1080,
  "split": "train",
  "group_key": "sequence-001"
}
```

`split` 可取 `train`、`val` 或 `test`。相同 `group_key` 的图片会保留在同一个切分中。

### 5.4 Label Studio 导出

平台也能识别受支持的 Label Studio JSON/ZIP 导出。导出中的图片路径必须能从所选目录解析，标签必须与登记时使用的类别一致。

对于完全未标注的 Label Studio 导出，需要在“初始类别”中填写类别名称。

### 5.5 默认数据切分

没有显式 `split` 时，平台当前使用：

- 训练集：80%
- 验证集：20%
- 测试集：0%
- 随机种子：42

相同输入会获得稳定的切分结果。平台不会仅根据 `images/train/` 或 `images/val/` 目录名称推断切分。

## 6. 登记数据集

所有内部使用者都可以登记数据集。

1. 进入“数据集”。
2. 点击右上角“登记服务器数据集”。
3. 选择“允许目录”。
4. 浏览并进入数据集所在目录，或填写相对路径。
5. 选择任务类型：
   - 目标检测
   - 实例分割
6. 根据数据来源填写“初始类别”。
7. 填写唯一的数据集名称和可选描述。
8. 点击“分析目录”。
9. 等待后台任务完成，确认源格式、图片数、标注数和切分数量。
10. 分析通过后点击“登记数据集”。
11. 登记完成后点击“查看数据集”。

分析和登记可能需要读取全部图片。大型数据集请等待后台进度完成，不要连续重复提交。

如果分析结果与预期不符，应先修正服务器上的源数据，再重新分析。分析后又修改了源文件时，平台会拒绝使用旧的分析结果登记。

## 7. 查看和管理数据集

### 7.1 数据集列表

数据集列表显示：

- 名称和描述
- 当前版本
- 媒体、类别和标注数量
- 当前状态
- 更新时间

可以按名称搜索或按状态筛选，并使用刷新按钮重新加载。

### 7.2 数据集状态

| 状态 | 含义 |
|------|------|
| 扫描中 | 平台正在分析或登记数据 |
| 待标注 | 数据集没有可用于训练的完整标注 |
| 审核中 | 存在进行中的 Label Studio 审核任务 |
| 可训练 | 当前版本校验通过并且包含标注 |
| 校验失败 | 数据格式、文件或标注没有通过校验 |
| 已归档 | 数据集只读，不能再创建审核或训练任务 |

### 7.3 数据集详情

点击数据集后可以查看以下页签：

- **概览**：媒体、标注、版本、数据体积、类别分布和完整性校验。
- **文件**：按文件名、切分和标注状态筛选；支持表格与缩略图视图。
- **格式与划分**：来源格式、任务类型、规范格式和 train/val/test 分布。
- **类别**：类别标注数量和占比。
- **版本**：版本来源、父版本、图片数、标注数、审核会话和 COCO 文件路径。
- **Label Studio 审核**：创建和管理审核任务。
- **UnitTrain 训练**：提交训练并查看当前数据集的训练记录。

### 7.4 版本原则

- 已发布版本显示“不可修改”。
- Label Studio 审核不会覆盖输入版本，而是生成下一个版本。
- 训练任务固定引用所选版本，之后产生新版本不会改变已提交的训练。
- “当前版本”代表平台最新发布版本；历史版本仍可查看和训练。

### 7.5 归档数据集

所有内部使用者都可以从数据集列表的操作菜单中归档数据集。

归档后：

- 数据集和历史版本仍然保留。
- 数据集变为只读。
- 不能创建新的审核任务。
- 不能提交新的训练任务。

归档不是删除操作。

## 8. Label Studio 审核

### 8.1 创建审核任务

1. 打开数据集详情。
2. 进入“Label Studio 审核”。
3. 确认页面显示“Label Studio 在线”。
4. 点击“创建审核任务”。
5. 选择作为输入的不可变数据集版本。
6. 点击“创建审核任务”。
7. 等待平台完成创建项目、配置标签和导入任务。

大型数据集会显示后台阶段和处理数量。任务就绪后会出现 Label Studio Project ID 和跳转按钮。

### 8.2 在 Label Studio 中审核

1. 点击“在 Label Studio 中打开”。
2. 如有提示，使用 Label Studio 账号登录（每个新的浏览器配置通常需要登录一次）。
3. 修改、增加或删除目标框/分割标注。
4. 提交完成的任务。
5. 回到平台刷新审核任务，查看完成数量和进度。

当前版本要求导出结果包含全部输入图片任务。因此：

- 可以修改一张图片上的标注。
- 可以让图片保持无标注状态。
- 不要在 Label Studio 中新增外部图片任务。
- 不要删除整张图片对应的 Task。

“审核任务”页面可以集中查看所有数据集的审核状态和进度。

### 8.3 结束审核并生成版本

确认审核结果可以发布后：

1. 在数据集的“Label Studio 审核”页签找到任务。
2. 点击“结束审核并生成版本”。
3. 阅读不可撤销提示并确认。
4. 等待平台导出、转换、校验和发布。
5. 任务完成后会显示输出版本，例如 `v2`。

输出版本是不可变版本。如果仍需修改，应基于该输出版本创建新的审核任务。

### 8.4 删除审核任务

处于“就绪”或“审核中”的任务可以删除。删除审核任务会：

- 删除对应的 Label Studio Project。
- 删除平台中的审核任务记录。
- 保留原始数据集及其所有已发布版本。

该操作不可恢复。它与“删除数据集图片”不是同一个功能。

### 8.5 审核失败与重试

审核任务失败后会显示错误摘要和“重试”按钮。先确认 Label Studio 已恢复在线，再执行重试。

重复重试不会覆盖已经成功发布的版本。如果错误涉及图片路径、类别或导出任务缺失，应先联系数据工程师处理数据问题。

## 9. UnitTrain 训练

### 9.1 提交训练任务

提交训练需要满足：

- 页面显示“UnitTrain 在线”。
- 数据集状态是“可训练”。
- 至少存在一个不可变版本。

操作步骤：

1. 打开数据集详情。
2. 进入“UnitTrain 训练”。
3. 点击“提交训练任务”。
4. 选择数据集版本。
5. 选择模型规模。
6. 设置 Batch Size 和 Epochs。
7. 确认自动生成的任务名称。
8. 点击“提交训练”。

当前页面使用 Ultralytics 框架，并根据任务类型提供 YOLO 检测或实例分割模型选项。

Batch Size 过大可能导致 GPU 显存不足。没有明确经验时，先使用默认值或向训练环境管理员确认。

### 9.2 查看训练任务

“训练任务”页面显示：

- 任务名称
- 数据集和固定版本
- 任务类型
- 状态
- Epoch 进度
- 主要指标
- 运行耗时

点击任务可进入详情页。运行中的任务每隔数秒自动刷新。

### 9.3 训练详情

训练详情包括：

- 当前状态和 Epoch 进度
- Loss 曲线
- mAP 曲线
- 最终指标
- 训练参数
- 训练日志
- UnitTrain 任务链接
- 输出模型入口

运行中的任务可以停止。提交阶段失败且尚未在 UnitTrain 中创建 Run 时，可以使用“重试提交”。

训练失败时，先阅读页面顶部错误信息和训练日志。涉及 GPU、模型环境或数据导出路径的问题，请联系平台维护人员。

## 10. 查看模型

训练成功后，平台会在“模型”页面生成模型记录。

模型列表和详情可查看：

- 模型名称和框架
- 来源训练任务
- 数据集及版本
- mAP、Precision 和 Recall
- 模型文件路径和体积
- 类别列表及分类别指标
- 评估输出文件

模型必须始终关联到明确的数据集版本，不能只记录数据集名称。

## 11. 系统管理

所有内部使用者都可以进入“系统管理”。

### 11.1 访问目录

- 添加服务器来源目录。
- 设置显示名称和说明。
- 启用或停用目录。

用户登记数据集时只能选择已启用的目录。目录必须是服务器上的有效绝对路径，并且平台服务需要有读取权限。

### 11.2 服务连接

“服务连接”显示 Label Studio 和 UnitTrain 的地址、版本、连接状态及 API Key 是否已配置。

点击“测试连接”只验证平台后端能否连接对应服务。显示离线时，普通用户应联系管理员，不要自行修改浏览器地址或 Token。

### 11.3 审计日志

审计日志记录数据集、版本、审核、训练、模型和系统操作，可用于追踪资源和时间；平台不记录用户身份。

## 12. 常见问题

| 现象或错误 | 处理方法 |
|------------|----------|
| 平台页面打不开 | 确认浏览器与服务器处于同一网络，并检查服务器 Web 容器是否监听 `0.0.0.0:8080` |
| 找不到服务器目录 | 目录未被管理员加入允许目录，或目录已停用 |
| `directory contains multiple supported annotation sources` | 所选目录中存在多个可识别 JSON/ZIP 标注源；只保留一个正式标注源 |
| `source image file does not exist` | JSON 中图片路径与实际目录不一致；使用类似 `images/00001.jpg` 的相对路径 |
| 分析结果显示 0 个标注 | 当前是纯图片目录，或者 JSON 未被识别为支持的标注格式 |
| 分析完成但不能登记 | 分析未通过、缺少数据集名称，或分析后源文件发生变化 |
| Label Studio 显示离线 | 点击“重新检测”；仍离线时联系管理员检查服务和 API Token |
| Label Studio 链接打不开 | 联系管理员检查公开访问地址；浏览器不能访问容器内部地址或服务器回环地址 |
| 审核导出提示缺少任务 | 不要删除 Label Studio Task；确认项目仍包含全部输入图片 |
| 审核一直等待后台任务 | 刷新页面；若长期无进度，联系管理员检查 Worker 和 Redis |
| UnitTrain 显示离线 | 点击“重新检测”；仍离线时联系管理员检查宿主机训练 API |
| 无法提交训练 | 确认数据集为“可训练”且 UnitTrain 在线 |
| 训练失败 | 查看错误摘要和训练日志；显存、模型环境和数据路径问题需要管理员处理 |

向管理员反馈问题时，请提供：

- 发生时间
- 页面名称
- 数据集名称和版本
- 审核任务 ID 或训练任务 ID
- 页面显示的错误信息

不要发送密码、API Token、Cookie 或完整环境配置文件。

## 13. 当前功能边界

当前网站尚未提供：

- 多个数据集的合并
- 数据集版本之间的差异对比
- 审核过程中删除整张图片并自动生成排除记录
- 浏览器直接上传本地数据集

这些操作不能通过直接修改已发布版本目录替代。需要相关能力时，请联系数据工程师或管理员。
