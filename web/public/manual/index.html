使用手册 · 部门内部版

视觉数据集管理平台

从服务器数据登记、Label Studio 标注审核，到 UnitTrain 训练和模型查看的一站式操作说明。

适用对象：数据集维护人员、标注审核人员、模型训练人员 平台地址：http://10.10.16.58:8080
1 准备数据 放入服务器允许目录
2 分析并登记 生成不可变 v1
3 审核标注 在 Label Studio 修正
4 发布新版本 审核结果生成 v2
5 训练与查看 提交训练并查看模型
01

快速开始

平台统一管理视觉数据集、Label Studio 审核任务、UnitTrain 训练任务以及训练输出模型。平台本身不设置登录页，在同一局域网内直接打开服务器地址即可进入数据集页面。

版本原则

已发布的数据集版本不可修改。需要调整 v2 时，应从 v2 创建新的审核任务，完成后生成 v3，而不是覆盖原版本。

左侧导航

入口主要用途
数据集登记、搜索、查看、版本管理和归档数据集。
审核任务查看所有 Label Studio 审核任务及完成进度。
训练任务提交并查看 UnitTrain 训练任务、指标与日志。
模型查看训练完成后产生的模型及其来源版本。
系统管理管理来源目录，检查外部服务连接和查看审计日志。
02

准备数据集

当前平台从服务器目录读取数据，不是浏览器上传工具。数据集必须提前放到服务器，并位于“系统管理”中启用的允许访问目录下面。

纯图片目录

没有现有标注时使用。登记时需要填写初始类别，多个类别使用英文逗号分隔。

dataset/
└── images/
    ├── 00001.jpg
    ├── 00002.jpg
    └── 00003.png

COCO 数据集

推荐用于已有检测框或实例分割标注的数据。一个目录只保留一份可识别标注文件。

dataset/
├── images/
│   ├── 00001.jpg
│   └── 00002.jpg
└── annotations.json

COCO 文件要求

annotations.json 必须是完整 COCO 对象，至少包含以下三个数组：

{
  "images": [],
  "annotations": [],
  "categories": []
}
  • images[].file_name 必须是相对于数据集目录的有效路径，例如 images/00001.jpg。
  • 检测框格式为 [x, y, width, height]，不是 [x1, y1, x2, y2]。
  • 检测框和分割掩码不能超出真实图片尺寸。
  • 同一目录只能存在一个可识别的 COCO 或 Label Studio 标注源。
  • 不支持同时放置 annotations/train.json 和 annotations/val.json；多份 COCO JSON 应先合并。

保留已有切分

如需保留训练集、验证集或测试集划分，可在 COCO 的 images[] 中增加 split；连续帧等关联图片可使用相同 group_key，平台会把它们放入同一切分。

{
  "id": 1,
  "file_name": "images/00001.jpg",
  "width": 1920,
  "height": 1080,
  "split": "train",
  "group_key": "sequence-001"
}
默认切分

未显式设置 split 时，平台按 80% / 20% / 0% 划分训练集、验证集和测试集，随机种子为 42。目录名 images/train 或 images/val 不会自动决定切分。

03

登记数据集

  1. 进入数据集页面，点击右上角“登记服务器数据集”。
  2. 选择允许目录和任务类型，再输入相对路径或在目录浏览区定位数据集。
  3. 纯图片目录填写初始类别；COCO 数据集会自动读取类别。
  4. 填写数据集名称和可选描述，然后点击“分析目录”。
  5. 核对源格式、媒体数、标注数、类别和切分结果。
  6. 确认无误后点击“登记数据集”，等待后台任务完成并生成 v1。
分析之后不要修改源文件

如果分析结果与预期不符，先修正服务器数据再重新分析。分析完成后又修改了源文件，平台会拒绝使用旧结果登记。

04

管理数据与版本

数据集状态

状态含义
扫描中平台正在分析或登记数据。
待标注当前版本没有可用于训练的完整标注。
审核中存在进行中的 Label Studio 审核任务。
可训练当前版本校验通过并且包含标注。
校验失败数据格式、文件或标注没有通过校验。
已归档数据集只读，不能再创建审核或训练任务。

查看文件与标注

数据集详情的“文件”页签支持表格和网格视图。网格缩略图和右侧单图预览会将已有检测框叠加在原图上，不同颜色代表不同目标类别。

版本与归档

  • 已发布版本始终不可修改；每次审核完成后生成下一个版本。
  • 训练任务必须绑定明确的数据集版本，后续版本不会改变已有训练输入。
  • 归档会保留数据集、历史版本和文件，只是将数据集改为只读。
  • 归档后不能创建新审核或训练任务；归档不是删除操作。
05

Label Studio 审核

  1. 在数据集详情中进入Label Studio 审核页签，基于当前版本创建审核任务。
  2. 等待任务显示为“就绪”或“审核中”，点击“在 Label Studio 中打开”。
  3. 新浏览器首次访问 Label Studio 时，使用部门提供的账号登录。
  4. 逐张修改、增加或删除目标框或分割标注，并提交完成的任务。
  5. 回到平台刷新任务，确认完成数量和进度。
  6. 确认全部结果后，点击“结束审核并生成版本”。
当前不能在审核中删除图片

导出结果必须包含全部输入图片任务。可以删除图片上的标注框，但不能通过 Label Studio 从数据集版本中移除图片。

结束或删除审核任务

  • 结束审核会导出结果并生成不可变的新版本，例如 v1 生成 v2。
  • 仍需修改时，应基于新版本再创建一次审核任务。
  • 删除“就绪”或“审核中”的任务会删除对应 Label Studio Project 和平台任务记录，但不会删除数据集及其已发布版本。
06

UnitTrain 训练

提交前检查

  • 页面显示“UnitTrain 在线”。
  • 数据集状态为“可训练”。
  • 选择包含完整标注的不可变版本。
  • 确认任务类型、模型、批大小、学习率、图片尺寸和训练轮数。

当前训练页面使用 Ultralytics 框架，并根据数据集任务类型提供对应的 YOLO 检测或实例分割模型选项。

训练详情

训练详情页集中显示运行状态、Loss 曲线、mAP 指标、训练参数和实时日志。运行中的任务可以停止；提交阶段失败且还没有创建 UnitTrain Run 时，可以执行“重试提交”。

07

查看模型

训练成功后，平台会在“模型”页面生成模型记录。每条记录包含模型文件名、来源训练任务、数据集版本、任务类型、主要指标、文件大小和创建时间。

  • best.pt 通常是验证指标最优的权重。
  • last.pt 是最后一个训练轮次保存的权重。
  • 模型必须关联到明确的数据集版本，不能只记录数据集名称。
08

系统管理

访问目录

登记数据集时只能选择已启用的来源目录。目录必须是服务器上的有效绝对路径，并且平台 API 和后台 Worker 都需要具有读取权限。

  1. 进入系统管理 → 访问目录。
  2. 点击“添加目录”，填写显示名称和服务器绝对路径。
  3. 保存后确认目录处于启用状态，再回到数据集登记页面选择。

服务连接与审计日志

  • “服务连接”显示 Label Studio 和 UnitTrain 的地址、版本、状态以及 API Key 是否已配置。
  • “测试连接”只验证平台后端能否连接对应服务，不代表浏览器一定能直接访问该地址。
  • “审计日志”记录数据集、版本、审核、训练、模型和系统操作，用于追踪资源变化和时间。
09

常见问题

登记时看不到目标服务器目录

先到“系统管理 → 访问目录”确认目录已经添加并启用。如果目录存在但仍不可见，请联系维护人员检查平台容器的挂载路径和读取权限。

分析提示存在多个标注源

同一数据集目录只保留一个可识别的 COCO JSON 或 Label Studio 导出。将多份 COCO JSON 合并成一个文件后再重新分析。

分析提示图片文件不存在

检查 images[].file_name 是否相对于所选数据集目录，并确认大小写、扩展名和子目录完全一致，例如 images/00001.jpg。

Label Studio 显示离线或无法打开

先在“系统管理 → 服务连接”测试后端连接。如果平台显示在线但浏览器打不开，通常是 Label Studio 的公开地址或服务器端口没有对局域网开放，需要联系维护人员处理。

任务长时间停留在等待后台任务

不要重复提交同一操作。记录任务名称和发生时间，联系维护人员检查 Worker、Redis 和任务日志。

UnitTrain 返回训练失败

打开训练详情，先阅读错误摘要和日志末尾。若是提交阶段失败且没有 UnitTrain Run，可以尝试“重试提交”；其他错误请连同任务 ID 和日志交给维护人员。

10

当前限制

  • 平台读取服务器目录，暂不支持直接从浏览器上传完整数据集。
  • 一个数据集目录只能包含一个可识别的标注源。
  • Label Studio 审核阶段可以修改标注，但暂不支持从数据集版本中删除图片。
  • 已发布版本不可编辑，所有变更通过新审核任务生成新版本。
  • 数据集之间的合并、去重和图片增删功能尚未提供。
需要帮助时提供什么信息

请记录数据集或任务名称、数据集版本、页面错误信息和发生时间。不要在聊天或截图中发送 API Token、密码等凭据。
